# Sistema de Ocorrências Urbanas

Projeto para registro de problemas como buracos, vazamentos e rachaduras.

## Funcionalidades
- Cadastro de ocorrências
- Exclusão
- Listagem
- Filtro por categoria

## Tecnologias
- HTML
- JavaScript
- JSON Server

## Como rodar
json-server --watch db.json

Abrir index.html com Live Server
